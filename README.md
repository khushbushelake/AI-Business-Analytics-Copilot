# AI-Powered Business Analytics Copilot

## Project Overview

An interactive business analytics application combining Data Analytics, SQL, and Generative AI to analyze the Tableau Sample Superstore dataset.

## Features

- Business KPI dashboard
- Regional and category analysis
- Profitability analysis
- Monthly performance trends
- Shipping performance
- Automatic business insights
- Natural-language Business Copilot
- Business recommendations

## Dataset

Tableau Sample Superstore

- 8,399 rows
- 30 columns
- Order dates: 2012–2015

## Technologies

- Python
- Pandas
- NumPy
- SQLite
- Streamlit
- Google Gemini API
- Tableau Hyper API
- Google Colab
